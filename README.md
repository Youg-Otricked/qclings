## C^4lings

Learn C^4 through broken programs!

### Setup:

Install the Quantum C Version Manager

There is a .deb available along with binaries on the latest release. Waiting for a webi package to be approved.
[Github](https://github.com/Youg-Otricked/quantum-c-version-manager)

Setup and install
```bash
mkdir qclings
cd qclings
qcm init
qcm add qclings@
cp dependencies/qclings@/* . -R
./qclings setup
```

### Use:

Just run `./qclings`
